## Principles digest (binding — full text in DESIGN.md §1)

1. Determinism first; the LLM sidecar only produces labels/captions, never anything
   load-bearing. Every feature works with no LLM configured.
2. Token economy of all default output; formats are golden-tested.
3. `core/` is pure: DomSnapshot JSON in → PageMem/Diff/text out. Playwright calls are
   allowed ONLY in `core/snapshot.py` (evaluate wrapper), `core/locate.py`, and
   screenshot clipping. Never per-element round trips.
4. `model.py` and the §4 output formats are FROZEN. Add optional fields; never
   repurpose. Renderer changes require updating golden files + DESIGN.md together.
5. No site-specific heuristics, ever.
6. Defaults need zero flags; complexity is opt-in.
7. Every phase ends with a working tool (`make lint test` green, prior verbs intact).
8. Errors name the recovery action ("run 'ebrowse outline'").

## Layout & commands

- `src/ebrowse/` — package (see DESIGN.md §7 for module map).
- `tests/fixtures/pages/` — fixture site; `list/table/huge.html` are generated by
  `python tests/fixtures/generate.py` (edit the generator, not the output).
- `make setup` — uv sync + playwright chromium.
- `make test` — pure tests only (fast, no browser).
- `make test-browser` — includes `browser`/`e2e` marks. `make lint` / `make fmt`.
- Dev harness (Phase 1+): `uv run python -m ebrowse.dev <url> outline`.
